## 5. แนวทาง implement สำหรับ agent ถัดไป

1. **Master data `subjects`** — สร้างรายการโปรแกรมตามตาราง §1 (แยก Private/Group Balance Play)
2. **Backoffice `catalog_items` / `price_rules`** — เก็บราคาขาย + เช่าอุปกรณ์ (integer satang หรือ minor units)
3. **เชื่อม enrollment** — เมื่อขายแพ็ก → `POST /courses` หรือ top-up wallet แล้วจอง
4. **Commission** — ต่อ SKU ใน `catalog_items` metadata สำหรับ Freelance (ยังไม่มี field — อาจใช้ `price_rules` kind=`COMMISSION`)
